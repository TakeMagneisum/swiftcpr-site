# Swift CPR demo

A plain static landing-page demo prepared for GitHub and Cloudflare Pages.

## Cloudflare Pages settings

- Framework preset: None
- Build command: leave blank
- Build output directory: `dist`
- Root directory: repository root

The demo includes `noindex` metadata and a blocking `robots.txt`. Remove both
before treating the site as a public launch.

No active credentials, certification issuer, pricing, service area, contact
details, partner affiliations, or booking functionality are represented yet.
